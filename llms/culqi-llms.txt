# Culqi

> Culqi is a Peruvian online payments platform and a Grupo Credicorp / Krealo company. Its REST API v2 lets businesses accept card, Yape, PagoEfectivo, mobile wallet and Cuotealo (installment) payments in PEN and USD. Card data is tokenized client-side against a PCI-scoped secure host (secure.culqi.com) using a public key (pk_); all money movement, subscriptions and webhooks run server-side against api.culqi.com with a secret key (sk_).

Generated by API Evangelist from apis.yml and the repository artifacts (method: generated). Culqi does not publish its own llms.txt.

## APIs

- [Tokens API](https://docs.culqi.com/es/documentacion/pagos-online/api-directa/introduccion/): Client-side tokenization of card and Yape credentials on the secure host.
- [Charges API](https://docs.culqi.com/es/documentacion/pagos-online/cargo-unico/resumen/): One-time charges (cargos) against a token or saved card, with capture holds and Cuotealo installments.
- [Orders API](https://docs.culqi.com/es/documentacion/pagos-online/pago-efectivo/resumen/): Payment orders for PagoEfectivo (CIP) and bank transfers.
- [Refunds API](https://docs.culqi.com/es/documentacion/pagos-online/devoluciones/resumen/): Full or partial refunds (devoluciones).
- [Customers API](https://docs.culqi.com/es/documentacion/pagos-online/clientes/resumen/): Stored customer profiles for saved cards and recurring payments.
- [Cards API](https://docs.culqi.com/es/documentacion/pagos-online/tarjetas/resumen/): Save tokenized cards to a customer.
- [Plans & Subscriptions API](https://docs.culqi.com/es/documentacion/suscripciones/resumen/): Recurring-billing plans and subscriptions.
- [Events & Webhooks API](https://docs.culqi.com/es/documentacion/pagos-online/webhooks/): Account events delivered to configured webhook endpoints.
